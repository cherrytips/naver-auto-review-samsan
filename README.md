# 삼산 한식뷔페 리뷰 도우미

QR → 키워드 선택 → 문장 복사 → 네이버 영수증 리뷰 화면(`https://m.place.naver.com/my/checkin`)으로 이동하는 중간 페이지입니다.
서버·빌드 없이 정적 파일만으로 동작하며(외부 라이브러리 없음), 개인정보를 수집하지 않습니다.

## 파일

| 파일 | 용도 |
| --- | --- |
| `index.html` | 화면 구조(마크업) |
| `css/style.css` | 디자인 (색상 변수, 다크모드 포함) |
| `js/config.js` | **매장명·네이버 주소·키워드·문장 설정** (자주 고치는 파일) |
| `js/app.js` | 문장 생성·복사·이동 동작 (보통 수정 불필요) |
| `qr/review-qr.png` | 인쇄용 QR (1024px, 오류정정 H) |
| `qr/review-qr.svg` | 확대 인쇄용 벡터 QR |

`js/config.js`가 `js/app.js`보다 먼저 불러와져야 합니다(`index.html`의 `<script>` 순서 유지).
ES module은 `file://`로 열면 막히므로 일반 `<script>`를 사용합니다.

## 키워드·문장·링크 수정

`js/config.js`의 `CONFIG` 블록만 고치면 됩니다.

- `reviewUrl`: 버튼을 눌렀을 때 이동할 네이버 주소
- `openInNaverApp`: `true`면 네이버 앱이 깔린 폰에서는 앱 안에서 엽니다(없으면 브라우저). 실기기에서 문제가 생기면 `false`로 바꾸면 예전처럼 브라우저로만 엽니다.
  - Android는 `intent://` 링크로 앱을 열고, 앱이 없으면 브라우저가 알아서 원래 주소로 보냅니다.
  - iPhone은 `naversearchapp://` 링크로 앱을 엽니다. 앱이 없으면 Safari가 '주소가 유효하지 않음' 알림을 잠깐 띄운 뒤 1.5초 후 브라우저로 이동합니다(웹에서는 피할 수 없음).
  - 네이버 앱 QR 스캐너로 들어온 경우에는 앱 안에서 그대로 이동합니다.
- `style`: 문장 끝 모양(`endings`: `.` `!` `~` 등과 나올 비율), 표정 이모지 목록(`emojis`), 이모지 개수 비율(`emojiCount`, 최대 2개)
- `openers`: 문장 앞에 붙는 중립적인 방문 문장 (칭찬 없이)
- `keywords`: `label`은 화면에 보이는 칩 이름, `phrases`는 그 키워드를 골랐을 때 무작위로 쓰이는 표현입니다. 키워드마다 3~4개를 준비하고, 과장된 표현은 넣지 않습니다.

손님이 고른 키워드의 표현만 문장에 들어가고, 같은 키워드를 골라도 표현과 순서가 매번 달라집니다.
`phrases` 끝의 마침표는 `style` 설정에 따라 `!`·`~`로 자동으로 바뀌고 표정 이모지가 0~2개 붙습니다(전부 마침표로만 끝나지 않음).

## 배포 (GitHub Pages)

`main` 브랜치에 push하면 1~2분 뒤 자동으로 반영됩니다. 주소는 바뀌지 않으므로 QR을 다시 인쇄할 필요가 없습니다.

```bash
git add -A && git commit -m "키워드 수정" && git push
```

## QR 다시 만들기 (주소가 바뀐 경우에만)

```bash
npx --yes qrcode@1.5.4 -e H -w 1024 -o qr/review-qr.png "<페이지 주소>"
npx --yes qrcode@1.5.4 -e H -t svg -o qr/review-qr.svg "<페이지 주소>"
```

## 도입 전 실기기 테스트

아이폰(Safari)·갤럭시(삼성 인터넷, 크롬), 네이버 앱 설치/미설치, 로그인/비로그인 조합으로
QR 스캔 → 복사 → 네이버 이동 → '영수증' 버튼 → 촬영 → 붙여넣기까지 확인합니다.
네이버 앱 설치 시 앱 안에서 열리는지, 미설치 시 브라우저로 넘어가는지, 앱에서 돌아왔을 때 버튼이 다시 눌리는지,
네이버 앱 리뷰 입력란에 붙여넣기가 되는지 확인합니다. 카카오톡 등 인앱 브라우저로 열었을 때와 네이버 앱의 QR 스캐너로 찍었을 때도 확인합니다. 네이버 화면은 바뀔 수 있으니 한 달에 한 번 다시 점검합니다.
