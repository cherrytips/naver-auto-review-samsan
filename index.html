영수증 리뷰 이벤트

솔직한 후기라면 별점·내용과 상관없이 음료수 1캔을 드려요!

1오늘 식사 어떠셨나요?

해당하는 것만 골라 주세요. 여러 개 고를 수 있어요.

2리뷰 문장 확인하기

고른 내용으로 문장을 만들었어요. 자유롭게 고쳐 쓰셔도 돼요.

0자

직접 고친 문장은 그대로 둘게요. ‘다른 표현으로’를 누르면 새로 만들어요.

3복사하고 네이버로 이동

버튼을 누르면 문장이 복사되고 네이버 리뷰 화면으로 넘어가요.

자동 복사가 안 되는 브라우저예요.
위 문장을 길게 눌러 ‘전체 선택 → 복사’한 뒤 아래 버튼을 눌러 주세요.

네이버로 이동하기
직접 쓸게요 → 네이버로 바로 가기

네이버 화면에서는 이렇게 해 주세요

  1. ‘영수증’ 버튼을 눌러요
  2. 받으신 영수증을 촬영해요
  3. 리뷰 입력란을 길게 눌러 ‘붙여넣기’
  4. 사진 첨부 후 등록, 매장 ‘저장’까지 눌러 주세요

완료 화면을 직원에게 보여 주시면 음료수를 드려요! 🥤
